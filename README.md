# じぶん天気

地点・表示・色・ひとことを自分でカスタマイズできる天気予報と、日本周辺の波の予想マップ。

公開ページ: https://papipasta.github.io/jibun-tenki/

## ご注意
表示している天気と波は、予測モデルの計算結果をそのまま出したもので、気象庁の予報ではありません。
防災や海のレジャー・船の運航などの判断には、必ず気象庁の警報・注意報・予報を確認してください。
